# MAIC 课程进度助手

一个用于 MAIC 课程学习的浏览器脚本，帮你查看课程进度，并自动推进 PPT 和视频课程。

## 用处

- 显示课程总数、已完成和待完成数量；
- 显示每门课程的当前进度；
- 一键自动处理未完成的 PPT 和视频；
- 测验会保留给用户自己完成，不会自动答题或提交。

## 安装方法

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)；
2. 点击 [安装 MAIC 课程进度助手](https://github.com/canxin121/maic-course-helper-public/raw/main/maic-course-helper.min.user.js)；
3. 在 Tampermonkey 中确认安装。

更新时重新点击同一个安装链接即可。

## 使用方法

1. 打开并登录 [MAIC](https://www.maic.tsinghua.edu.cn/)；
2. 进入课程页面，右下角会出现“MAIC 课程进度助手”面板；
3. 首次使用可点击“刷新课程”获取课程清单；
4. 需要自动学习时，打开“自动刷课”开关；
5. 想停止自动学习时，关闭“自动刷课”开关。

## 注意事项

- 测验不会自动完成，请在面板显示待完成后自行处理；
- 自动学习过程中请保持对应浏览器标签页可用；
- 脚本只会在 MAIC 网站内运行，不会收集或上传你的登录信息。
