# MAIC 课程进度助手

适用于 `https://www.maic.tsinghua.edu.cn/*` 的课程进度 Userscript。

## 一键安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)；
2. 点击 [安装 MAIC 课程进度助手](https://github.com/canxin121/maic-course-helper-public/raw/main/maic-course-helper.min.user.js)；
3. 打开 MAIC，右下角会出现“MAIC 课程进度助手”。

更新版本时，重新点击同一个安装链接即可。

## 功能

- 课程清单与进度缓存；
- 一个“自动刷课”总开关；
- PPT/视频自动推进；
- 测验始终留给用户，不自动答题、不提交。

## 隐私

脚本只在 `www.maic.tsinghua.edu.cn` 运行，不收集、不上传 Cookie、Token 或其它凭据。
